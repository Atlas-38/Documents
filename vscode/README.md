# Guia ràpida de Markdown

Aquest README mostra els elements principals de **Markdown** per crear documents clars des de VS Code.

## Format de text

Es pot escriure en **negreta**, *cursiva* o ~~ratllat~~. Per representar una ordre o una paraula tècnica, utilitza `codi en línia`.

### Llistes

Una llista no ordenada:

- Obrir un fitxer Markdown a VS Code
- Escriure el contingut amb Markdown
- Consultar la previsualització

Una llista ordenada:

1. Crear el document
2. Revisar-ne el format
3. Publicar-lo

Tasques pendents:

- [ ] Afegir el contingut
- [ ] Revisar els enllaços
- [ ] Compartir el README

## Bloc de codi

El nom del llenguatge després dels tres accents greus activa el ressaltat de sintaxi:

```python
def saluda(nom):
    return f"Hola, {nom}!"

print(saluda("món"))
```

## Taula

| Element | Sintaxi | Exemple |
| --- | --- | --- |
| Títol | `#` | `# Títol` |
| Negreta | `**text**` | **text** |
| Codi | `` `text` `` | `print("Hola")` |
| Enllaç | `[text](url)` | [Markdown Guide](https://www.markdownguide.org/) |
